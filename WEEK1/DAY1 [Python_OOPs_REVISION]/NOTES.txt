
<--------------------- 🔹🔹One-line memory trick🔹🔹-------------->
Class       → Blueprint
Object      → Instance of blueprint
Constructor → Initializes object
self        → Current object
Instance    → Individual data
Class       → Shared data


<-----------------📊 Difference b/w instance,class and static method — Very Important ------------>
__________________________________________________________________________________
| Feature              | Instance Method | Class Method   | Static Method        |
| -------------------- | --------------- | -------------- | -------------------- |
| First parameter      | `self`          | `cls`          | None                 |
| Works with           | Object          | Class          | Neither specifically |
| Access instance data | ✅              | ❌             | ❌                  |
| Access class data    | ✅              | ✅             | ❌ directly         |
| Decorator            | None            | `@classmethod` | `@staticmethod`       |
-----------------------------------------------------------------------------------


<-------------- 🧠 MEMORY TRICK------> 
INSTANCE → self → Object
CLASS    → cls  → Class
STATIC   → nothing → Utility

>>>>>>>>>🟦Child/Derived Class:
