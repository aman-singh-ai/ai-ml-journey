<---------------------------------🔹🔹Inheritance ; [Parent & Child class]🔹🔹-------------------------------->
Inheritance:
     Inheritance is an OOP mechanism in which a child class inherits properties and methods from a parent class.

Parent/Base Class:
           A parent class is a class whose properties and methods are inherited by another class.

Child/Derived Class:
           A child class is a class that inherits properties and methods from a parent class.

Method Overriding:
           is the process in which a child class provides its own implementation of a method already defined in its parent class.

super():
           is used to access methods and attributes of a parent class from a child class.


<---------------------------🔥 Important Difference 🔥--------------------------->

                            #Inheritance🔹

What it does: 
     The child class reuses or inherits the existing functionality of the parent class.

Concept:
     It defines a relationship 
     (e.g., A Student is a Person).
          
                              Person
                                ↓
                              Student

               ______________________________________________

                          #Method Overriding🔹

What it does:
     The child class changes or provides its own specific implementation for a method that already exists in the parent class.
Concept:
     It changes how a specific action is performed 
     (e.g., A Student introduces themselves differently than a general Person).
                             
                             Person.introduce()
                                     ↓
                             Student.introduce()


<--------------------------🧠🧠 When to Use What?🧠🧠----------------------------------->
_______________________________________________________________________________________
|               Situation                                     |      Use              |
| ------------------------------------------------------------| --------------------- |
| Want to reuse the functionality of an existing class        | **Inheritance**       |
| Want to keep common functionality in the parent class       | **Inheritance**       |
| Want to provide additional functionality to the child class | **Inheritance**       |
| Want to change the behavior of a parent class method        | **Method Overriding** |
| Need to use or execute the parent class constructor         | **`super()`**         |
| Need to call the overridden method of the parent class      | **`super()`**         |
---------------------------------------------------------------------------------------


<-----------------------⚠️⚠️ Don't Confuse Overriding with Overloading ⚠️⚠️-------------------------->

                <--------- Overriding---------->
Concept: Same method name in both Parent and Child classes, but the child class changes the behavior
              Visual:Parent → show()
                     Child  → show() (Modified version)
                     
                <----------Overloading--------->
Concept: Same method name within the same class, but with different parameters or arguments.
Note: Unlike Java or C++, traditional method overloading is not directly supported in Python.
